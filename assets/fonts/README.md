Roboto is the existing interface font. Noto Sans JP supplies Japanese glyphs
for the Slint shell and native lyrics. Both are bundled for offline use.

- Noto Sans JP: https://github.com/google/fonts/tree/main/ofl/notosansjp
- Original variable TTF: `NotoSansJP[wght].ttf`, stored here as `NotoSansJP.ttf`.
- License: `OFL-NotoSansJP.txt` (SIL Open Font License 1.1).
- The widget license bundle and Windows package include this notice.
